# Spooky Bob

## About the Game

Spooky Bob is a fast-paced Halloween-themed collection game developed using **p5.js**. The objective is to collect falling snails and pumpkins to earn points while avoiding evil enemies. Players can choose their difficulty level and customize how long they want to play.

Be careful! Clicking on an evil enemy or running out of time will end the game. Try to collect as many items as possible before the timer runs out.

## How to Play

1. Start the game and select your preferred difficulty level.
2. Choose your playing time using the plus and minus buttons.
3. Click **Start Game** to begin.
4. Click on falling snails and pumpkins to collect them and earn points.
5. Avoid clicking on evil enemies, as doing so will immediately end the game.
6. Try to achieve the highest score before the timer reaches zero.
7. Once the game ends, click **Retry** to play again.

## Features

- Three difficulty levels: Easy, Medium, and Hard.
- Customizable playing time from 30 to 60 seconds.
- Collectible items, including snails and pumpkins.
- Evil enemies that end the game when clicked.
- Scoring system to track collected items.
- Countdown timer to add a time-based challenge.
- Custom Halloween-themed backgrounds and visuals.
- Start screen and game-over screen.
- Background music and sound effects.
- Retry option to restart the game.
- Responsive canvas that adjusts to the browser window.

## Technologies Used

- **p5.js** – Game development, rendering, animations, and interaction.
- **JavaScript** – Game logic, scoring, difficulty settings, and timer.
- **HTML5** – Game structure.
- **CSS3** – Page styling and layout.

## Development Process

While developing Spooky Bob, I expanded the original game by introducing additional mechanics and visual elements. I implemented three difficulty levels with different falling speeds, spawn intervals, and enemy probabilities. I also added a customizable timer, scoring system, collectible items, custom backgrounds, and separate start and game-over screens.

To make the game more engaging, I included background music and sound effects, along with a retry option that allows players to start another round. The visual assets and audio resources were sourced online from platforms such as Pinterest and Google.
